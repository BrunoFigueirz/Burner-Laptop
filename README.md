# Burner-Laptop
Fazendo quase literal lobotomia em um Notebook win t23l CCE  de 2014, câmera, microfone, placa Wi-Fi, bateria e HD removidos, restam apenas a memória RAM e um pendrive em live boot. Ao desligar ou remover o pendrive, nada permanece salvo

# Notbook Fantasma

### O que é?
Um projeto de um verdadeiro **hardware frankenstein** onde transformei um notebook antigo em uma máquina minimalista, modular e focada em privacidade para estudos em cibersegurança.

O objetivo é simples: criar um "Notebook Fantasma" uma máquina difícil de rastrear, sem componentes desnecessários e que roda 100% via pendrive externo.

### Por que esse projeto existe?
- Reaproveitar hardware velho que iria para o lixo
- Criar um laboratório portátil com **mínimo rastro digital**
- Ter a possibilidade de trocar de identidade facilmente (MAC spoofing)
- Documentar todo o processo de forma honesta (com erros e tudo)

### Modificações Realizadas

- [x] Remoção completa da placa Wi-Fi interna
- [x] Remoção da câmera frontal
- [x] Remoção da bateria CMOS
- [x] Limpeza profunda de poeira interna
- [x] Remoção do drive de DVD
- [ ] Substituição do HD por SSD (É uma boa adição)
- [ ] Configuração final com Tails OS (se preferir o Kali ou qualquer outra distro live boot)

Esse notebook agora é como um agente secreto: não tem nome, não tem rosto, não tem Wi-Fi fixo. Só hardware mudo + adaptador USB descartável.

### Como funciona hoje
- Roda exclusivamente via **Live USB** (sem instalar nada no disco interno)
- Usa apenas adaptador Wi-Fi USB externo
- Identidade de rede pode ser trocada fisicamente + MAC spoofing
